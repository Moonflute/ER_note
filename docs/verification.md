- PDF 2페이지를 시각 확인. PDF에만 있는 요약·차팅 문구 3개 보존

- 첫 화면 소개 제목·설명·검색 안내·하단 부연 문구 제거. 검색창부터 표시
- 원문 자료가 연결된 CC 38개만 목록과 검색에 표시. 빈 분류 숨김
- 원문 데이터의 75개 CC와 573개 블록, 464개 항목은 변경 없음
- 주요 카드와 버튼 여백 축소, 문구를 `목록`, `출처`, `참고`, `초기화`, `위로`로 정돈
- 빨강 중심 색상 적용, 소아·정신과 범위는 짧게 보존
- 모바일 390 × 844, 데스크톱 1280 × 900에서 가로 넘침 없음
- CP·HA·N/V 검색 정상. 미수록 SOB는 카드 대신 빈 검색 결과
- 인계만 있는 CC는 인계 내용을 바로 펼침. 이전 미수록 CC 링크는 목록으로 복귀
- 체크·초기화·원문 출처 보기 정상. 브라우저 error·warn 없음
