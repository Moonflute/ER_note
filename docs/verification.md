# 베타 검증

## 데이터 보존

- 원본 5파일, 원문 텍스트 블록 573개 모두 대응표 연결
- 문진·신체진찰·인계 메모·예시를 포함한 464개 항목에 원문 출처 존재
- 정리 텍스트는 원문의 공백과 앞쪽 bullet만 정돈
- 정확히 동일한 중복 38건 통합. 차팅 예시 반복 소견은 통합하지 않음
- 원문 파일 SHA-256 일치, 미분류 블록·고유 ID 충돌·접근 불가능 section 없음
- 75개 CC 중 38개에 원문 자료 연결. 원문이 없는 37개는 자료 없음 표시
- 소아 6종 범위와 정신과 자료 범위를 명시
- PDF 2페이지를 시각 확인. PDF에만 있는 요약·차팅 문구 3개 보존

검증 명령: `python scripts/validate_data.py`

## 브라우저 검증

연결된 실제 브라우저에서 로컬 정적 HTTP 서버를 이용했습니다.

| 점검 | 결과 |
| --- | --- |
| 모바일 390 × 844 | 주요 증상 8개 확인, 가로 넘침 없음 |
| 작은 모바일 320 × 740 | 상세 화면 가로 넘침 없음 |
| 데스크톱 1280 × 900 | 주요 카드 4열과 분류 3열 정상 |
| CP / HA / SOB / N/V 검색 | 각각 흉통 / 두통 / 호흡곤란 / 오심·구토 1개 결과 |
| 한글 부분 검색 `어지` | 어지럼 결과 |
| 영어 `chest pain` | 흉통 결과 |
| 일치하지 않는 검색 | 빈 결과 안내 |
| 체크와 초기화 | 확인 수 증가 및 초기화 정상 |
| 원문 출처 dialog | 원본 파일·문단 번호·원문 일치 |
| 상세에서 목록 복귀 | 이전 검색어 유지 |
| 상세 구성 | CC 고유 문진·진찰이 먼저, 공통 문진·진찰이 뒤 |
| 인계·차팅 참고 | 본문 뒤, 차팅 예시에 체크박스 없음 |
| 브라우저 console | 검사 중 error·warn 없음 |

`node --check app.js`도 통과했습니다. 임상 내용의 최신성 검증은 이 검사 범위에 포함하지 않습니다.
