# 개념 자료와 근거

확인일: 2026-10-08. 현재 제공하는 37개 CC에 개념을 연결한다.

## 편집 범위

- 핵심 감별 3–4행, Hx/PEx 해석 4–5행, 해석 주의 한 문장.
- 전체 표시 문구 최대 420자. 반복 설명을 덜고 검사 적용 조건·배제 한계는 남긴다.
- 원문 문진은 변경하지 않는다. 새 설명은 별도 `data/cc-concepts.json`에 둔다.
- 의미가 불확실한 원문 약어는 추정하지 않는다.

## 근거 기록

- 모든 감별·Hx·PEx·주의 문장에 `sourceIds`를 연결한다.
- `sources`에는 출판사/학회, 판·장·절, URL, 확인일, 접근 범위를 기록한다.
- `publisher-excerpt`는 출판사가 공개한 본문 범위다. 해당 교재 전체 본문을 검토했다는 뜻이 아니다.
- `full-text`는 공식 지침/매뉴얼의 해당 절을 확인한 자료다.
- 최신 학회 지침과 교재의 설명을 대조한다. 원문을 길게 복제하지 않고 요약한다.
- 외국 기관의 처방·보고 체계를 국내 병원 오더로 옮기지 않는다.
- `itemIds`는 기존 문진 항목과의 대응이며, 빈 배열은 원문에 없는 개념 설명이다.
- 자동 검증은 범위·참조·길이를 검사한다. 임상 해석은 근거 본문으로 직접 검토한다.
