# 전체 CC 개념 검토

검토일: 2026-10-08 · 데이터 버전: `2026-10-08.5`

이전 검토에서 제공 중인 37개 CC를 대조했고, 35개 개념을 수정했다. 두통·어지럼에 분기 표시를 적용한 뒤, 사용자 피드백에 따라 어지럼의 시작 질문을 TRS로 맞췄다. 원문 보존 계층은 유지하고 문진 layout의 어지럼 질문 순서만 조정했다.

이번에는 성인 `adult-fever` 개념 1개를 추가해 총 38개를 제공한다. 기존 37개 개념과 원문 문진은 보존했다.

## 이번 누락의 원인과 수정 기준

초기 작업은 감별 4행·Hx/PEx 합계 5행·전체 420자를 먼저 제한했다. 이 과정에서 압통 위치·유발검사 결과를 일반적인 요약으로 바꾸고, Murphy처럼 주요 감별에 필요한 진찰을 빠뜨렸다.

이제 임상 핵심을 먼저 선정하고 반복 표현을 압축한다. 근거가 확인된 핵심을 글자 수나 행 수 때문에 삭제하지 않는다. 개별 설명은 80자 이하, 전체는 보통 500자 이하를 목표로 한다.

## 대조 항목

1. 해당 CC의 주요 응급 감별과 흔한 대체 원인이 빠졌는가.
2. 원문에 있는 증상 특이 Hx/PEx가 무엇을 구분하는지 알 수 있는가.
3. 위치·방사·안진·동공·청진·유발검사의 구체적인 결과와 의미가 있는가.
4. 정상/음성 소견의 배제 한계 또는 검사 적용 조건이 필요한가.
5. 같은 설명을 반복하거나 근거보다 강하게 단정한 문장이 있는가.

이번 검토는 위 범위의 누락과 해석을 확인한 기록이며, 모든 질환을 열거하는 목록은 아니다. 임상적 완전성을 자동 검증으로 보증하지 않는다.

## 두통·어지럼 분기 표시

- `headache`: 발병 속도/양상 변화에서 시작한다. SAH·감염·국소 이상/외상·GCA·ICP·안과 위험을 먼저 나누고, 이차성 위험 평가 후 편두통/긴장성 양상을 확인한다. 근육 압통과 경부강직 구분, 정상 진찰의 SAH 배제 한계는 보존했다.
- `dizziness`: 사용자가 먼저 묻는 TRS로 시작한다. 원문의 TRS·양상 → 지속시간/회복 → 발병 상황 → 귀·신경 증상 순서를 시작 흐름에 연결했다. 답을 해석할 때 신경·보행 위험, 지속+자발안진의 HINTS, 짧은 자세 유발 발작의 체위검사를 구분한다. 증상의 느낌만으로 중추/말초나 검사 경로를 결정하지 않는다.
- HINTS의 정상 HIT·방향전환 주시안진·skew 중 하나면 중추 의심, 말초 조합에서도 새 청력저하는 중추 재평가 단서다. 지속 증상의 움직임 악화를 자세 유발 발작으로 분류하지 않는다. Romberg의 의미와 한계, 자발 발작의 TIA 감별, 불확실 HINTS의 MRI 평가도 남겼다.
- 기존 감별/Hx/PEx 객체는 보존했다. 원문에 있던 TRS·양상 질문을 개념 Hx에 대응시키고 ACI History/GRACE-3 근거를 추가 연결했다. `flow.conceptRefs`는 모든 의미를 분기나 주석에 연결한다. 이는 의심 원인으로 안내하는 흐름이며 확진·배제 규칙이 아니다.
- 모바일은 양상/추가 확인을 왼쪽, 의심 원인을 오른쪽에 놓는다. 분기마다 클릭하거나 접지 않고 전체가 보이게 했다. 출처 버튼·장식 카드·색 띠는 추가하지 않았다.

## 성인 발열 분기 추가

- 성인 발열 원문 유무를 문진 템플릿·초진 all·과별 초진 순으로 하나씩 대조했다. 독립 발열 문진은 소아 자료이므로 이를 성인에 붙이지 않고 별도 `adult-fever`를 만들었다. 원문 체크리스트가 없는 `conceptOnly` 항목은 개념을 바로 열고 빈 탭을 표시하지 않는다.
- 시작 질문은 Tmax·측정법·기간, 동반 증상, U/D·Drug·노출이다. 패혈증·호중구감소성 감염·CNS 감염·열사병의 위험 분기 뒤에 호흡기·요로·복부·피부의 국소 진찰을 연결했다.
- CVAT+, crackle/경화 소견, 국소 Td/복막자극, 피부 발적/열감/압통, 삽입부 염증/잡음의 감별 의미를 해당 갈래에서 표시한다. 초점 없는 급성 발열에서는 위험 병력·노출을 재확인한 뒤 바이러스를 고려하며, 도관·인공판막·새 약·유행지 노출·지속/반복 발열의 대체 원인을 남겼다.
- 수막 자극·발진 부재의 배제 한계, 약물열의 배제 진단 성격, 고령의 낮은 체온/국소 소견 한계를 유지했다. MSD Fever, NICE NG253/CG151/NG240, CDC/NIOSH, EAU, IDSA와 복부 진찰 근거를 직접 대조했다. 지역사회 위험 기준을 ER 점수·처방 규칙으로 바꾸지 않았다.
- 표시 문구 합계 489자. 문진 탭/체크 수가 없어 상단 여백이 줄며, 기존 모바일 분기 표시를 사용한다. 각 문장은 80자 이하이고 핵심 진찰 결과는 해당 분기에 한 번씩만 넣었다.

## 밀도 검토

아래 글자 수는 실제 표시하는 질환명·label·설명·주의 문장의 합계다. `flow`가 있는 경우 시작 질문·단계·분기·주석·주의 문장을 센다. 실제 기기 높이·글자 확대에 따라 스크롤이 생길 수 있어 내용을 잘라내지 않는다. 기존 작은 글자·간결한 행 배치는 유지한다.

## 원문 보존과 불확실한 표현

- 원문 문진·PEx·참고사항과 그 대응표는 수정하지 않았다. 추가된 진찰 설명은 개념 데이터에만 두고 외부 근거를 연결했다.
- 원문에 없는 개념 항목의 `itemIds`는 빈 배열이다. 기존 항목과 대응되는 의미만 해당 layout ID로 연결한다.
- `LOM`, `neck level` 등 미확정 표현은 새 해석을 만들지 않는다. 원문의 운동 등급이나 불명확한 검사 지시를 표준으로 옮겨 적지 않는다.
- 교재 출판사 공개 본문과 해당 공식 지침/매뉴얼의 절을 확인했다. Tintinalli 전체 유료 본문을 검토한 것으로 표시하지 않는다.

## 검증 범위

- 원문 600개 항목·sourceItemIds 대응·제공 중인 37개 CC 연결·소아/성인/정신 범위.
- 모든 임상 행의 근거 연결·layout 항목 대응·스키마·문구 길이·CC별 검토 기록. 분기 표시의 기존 감별/Hx/PEx 전체 대응과 기존 인용 보존.
- JavaScript 문법과 기존 Node의 탭/체크 상태 검사. 브라우저 및 Pages 배포 상태 확인은 하지 않는다.
